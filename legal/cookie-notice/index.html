ARGOS Cookie Notice

Version 1.0-beta - Effective 17 August 2026

ARGOS currently uses cookies that are necessary to authenticate users and protect the Service. These cookies do not require an advertising profile and are not used for cross-site advertising.

Cookies currently set by ARGOS

Cookie Purpose Current duration Properties
argos_session Maintains the authenticated user session Up to 7 days by default; refreshed during an active session HttpOnly, Secure in production, SameSite=Lax, site-wide
argos_admin_session Maintains a separate authorised administration session Up to 8 hours by default HttpOnly, Secure in production, SameSite=Strict, site-wide

Authentication providers and connected third-party services may set their own cookies on their domains during sign-in or authorisation. Their notices apply to those cookies.

Browser storage

ARGOS currently uses browser localStorage for the selected UI language, device identifier, approximate location/time-zone preference, enabled-expert state, health display preferences, home grouping preference, local notes where durable editing is unavailable, voice settings and the name used on a shared list.

The service worker Cache API stores the public application shell so the interface loads reliably. It is versioned and old application-shell caches are removed during activation. The current application does not intentionally use browser storage for OAuth tokens or authenticated server-session credentials.

This inventory was reviewed for version 1.0-beta and will be updated after any analytics, authentication, offline-storage or caching change.

Your choices

Essential cookies are required for sign-in and security. Blocking them may prevent ARGOS from working. Logging out clears the active ARGOS session cookie.

ARGOS currently does not intentionally use non-essential analytics, advertising or cross-site tracking cookies. If that changes, we will update this Notice and provide a consent choice before setting non-essential cookies where required.
